# FSS_Helper

금융감독원 검사역이 **검사건별로** 검사업무를 관리하도록 돕는 Windows 앱입니다. 내부망에서도 쓸 수 있도록 국가법령정보(www.law.go.kr)와 OpenDART에 직접 연결합니다.

| 메뉴 | 하는 일 |
| --- | --- |
| 대시보드 | 진행 중 검사건, 기한 지남, 14일 일정, 관심기업 새 공시 |
| 검사건 | 검사건 추가·삭제, 진행 단계(완료/생략/다른 팀 담당), 지적사항·행위자별 제재 양정(과징금·과태료 구분), 검사건 문서 폴더, 메모·할 일 |
| 일정·할 일 | 달력과 할 일 |
| 문서 법규 검증 | 작성한 HWP/HWPX를 불러와 인용 법규가 기준일 법령과 맞는지 검증 |
| 서식·매뉴얼 | 가져온 매뉴얼·서식 보기(표 포함), 한글 원본 서식 그대로 작성 |
| 보조 기능: 법률 도우미 | 법·시행령·시행규칙·감독규정·세칙 펼쳐 보기, 1~5단 비교, 기준일 조회, HWPX 저장 |
| 보조 기능: 기업 개황·공시 | 기업개황, 최대주주, 재무, 공시 목록, 한글·PDF 저장 |
| 보조 기능: 양정 기준·계산기 | 과징금·과태료, 임원·직원·기관 양정 기준 |

국가법령정보 OC와 DART 인증키 받는 방법은 설정 화면에 안내되어 있고, 키 없이 법률 도우미나 기업 검색을 열면 안내 창이 뜹니다. 키는 PC에 암호화(DPAPI)해 저장하며 저장소에는 들어가지 않습니다. 다른 PC로 옮길 때는 비밀번호로 잠근 `.fsskey` 파일을 씁니다.

## 설치

릴리스의 `FSS_Helper-버전-x64-Setup.exe`(일반 PC) 또는 `-arm64-Setup.exe`(ARM PC)를 실행합니다. 관리자 권한 없이 `%LOCALAPPDATA%\Programs\FSS_Helper`에 설치됩니다.

## 업데이트

내부망에서 쓰므로 자동 업데이트는 기본으로 꺼져 있습니다. 새 설치 파일을 받아 다시 설치하면 데이터(`%APPDATA%\FSS_Helper`)는 그대로 남습니다. 배포 파일은 저장소 주인의 GitHub Secret으로 서명하므로 다른 사람이 만든 빌드는 업데이트로 받아들여지지 않습니다.

## 빌드

```
./gradlew test
./gradlew :app:run
./gradlew :app:createDistributable   # 앱 이미지
```

설치 파일은 GitHub Actions(`build.yml`)가 x64·ARM64용으로 만들고, 배포는 저장소 주인이 `v*` 태그를 올릴 때 `release.yml`이 합니다.
