# FSS_Helper

금융감독원 검사역이 검사업무에 늘 찾아보는 자료와 기준을 한곳에 모은 Windows 앱입니다. 내부망에서도 쓸 수 있도록 국가법령정보(www.law.go.kr)와 OpenDART에 직접 연결합니다.

모든 메뉴는 창 맨 위 탭으로 배치되어 있습니다(설정·앱 정보는 오른쪽 끝 아이콘).

| 메뉴 | 하는 일 |
| --- | --- |
| 홈 | 도구 카드와 최근 사용 목록(서식·매뉴얼 쪽·법령·기업·작성한 파일, 즐겨찾기) |
| 검사품질관리 매뉴얼 | 가져온 매뉴얼을 원본 모양(PDF) 그대로 보기, 목차·찾기 |
| 검사관련 서식 | 서식별 원본 보기(PDF), 원본에서 그 서식만 떼어 한컴오피스 한글 또는 이음오피스로 작성 |
| 법률 검색 | FSS_insights 방식: 항·호·목 바로 아래 위임 법규, 인용 법규는 따로. 1~5단 비교, 기준일 조회 |
| 기업 개황 | 기업개황·최대주주·재무·공시, 한글·PDF 저장 |
| 양정기준 | 임원·직원·기관 기준표 → 가중·감경 단계 시뮬레이션, 제재규정·세칙 원문 |
| 과징금 산정기준 | 법정부과한도액 × 부과기준율(세부평가) → 가중·감경 → 상한 시뮬레이션, 원문 |
| 과태료 산정기준 | 법정최고금액 × 예정비율(위반결과×동기) → 가중·감경 시뮬레이션, 원문 |
| 할 일 | To Do 목록(기한·중요 표시) |

매뉴얼·서식 원문은 내부 자료라 이 저장소에 넣지 않습니다. 앱에서 한글 파일을 가져오면 이 PC의 한글(한컴오피스)이 PDF로 바꿔 보여 주고, 서식 작성도 한글 자동화로 원본에서 잘라 만듭니다. 처음 한 번 한글이 접근 허용을 물으면 '모두 허용'을 누릅니다.

한글 대신 [이음오피스](https://github.com/pblsketch/ieumoffice-site)로 열 수도 있습니다(설정 > 한글 문서 열기: 자동/한컴오피스 한글/이음오피스). 한글이 없는 PC에서는 HWPX 서식을 앱이 직접 나눠 이음오피스로 열고, HWP 서식은 전체 원본을 엽니다. 원본 보기용 PDF는 이음오피스에서 PDF로 저장한 파일을 넣으면 됩니다.

국가법령정보 OC와 DART 인증키 받는 방법은 설정 화면에 안내되어 있고, 키 없이 해당 메뉴를 열면 안내 창이 뜹니다. 키는 PC에 암호화(DPAPI)해 저장하며 저장소에는 들어가지 않습니다.

## 설치

릴리스의 `FSS_Helper-버전-x64-Setup.exe`(일반 PC) 또는 `-arm64-Setup.exe`(ARM PC)를 실행합니다. 관리자 권한 없이 `%LOCALAPPDATA%\Programs\FSS_Helper`에 설치됩니다.

## 업데이트

내부망에서 쓰므로 자동 업데이트는 기본으로 꺼져 있습니다. 새 설치 파일을 받아 다시 설치하면 데이터(`%APPDATA%\FSS_Helper`)는 그대로 남습니다. 배포 파일은 저장소 주인의 GitHub Secret으로 서명하므로 다른 사람이 만든 빌드는 업데이트로 받아들여지지 않습니다.

## 빌드

```
./gradlew test
./gradlew :app:run
./gradlew :app:createDistributable   # 앱 이미지
```

설치 파일은 GitHub Actions(`build.yml`)가 x64·ARM64용으로 만들고, 배포는 저장소 주인이 `v*` 태그를 올릴 때 `release.yml`이 합니다.
